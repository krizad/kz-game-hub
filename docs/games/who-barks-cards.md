# หมาตัวไหน / Who Barks — character cards and image prompts

The 30 bilingual characters are implemented in `packages/types/src/dog-relay-cards.ts`. Each character is independent of a player's hidden role.

## User-supplied base image

The base has been moved to [dog-base.png](../../apps/web/public/images/who-barks/base/dog-base.png), served as `/images/who-barks/base/dog-base.png`. SHA-256: `442d0656a046150559778182c42821fd517d3f00fd83c8747db5bc9eab99419b`; 848 × 1264 pixels. This user-supplied file supersedes all earlier draft images and base descriptions.

Use the user-supplied dog-base.png as the authoritative character reference: a front-facing seated golden dog with floppy ears, round dark eyes, pink cheeks, a blue collar and gold bell, dark brown outlines, simple flat cartoon colors and a white background. Keep its exact seated pose, facial expression, body proportions and framing unchanged. Do not regenerate or redesign the base. Attach this original file directly for each variant, not a previously generated character card.

## Artwork and generation workflow

The 30 character images were generated with Google's `gemini-3.1-flash-image` model using the original base image and the individual prompts below. Artwork is saved in `apps/web/public/images/who-barks/cards/` as `dog-001.png` through `dog-030.png`. The [asset manifest](../../apps/web/public/images/who-barks/manifest.json) records each card's number, name, prompt, image path, model and image SHA-256. API credentials are not stored in these files.

Each card's `imageSrc` points to its generated artwork; the game retains its text fallback if an image fails to load. To create future variants, attach the original base image and use the corresponding prompt. Save replacements separately for review before changing the registered path. Card numbers/names are UI text, not part of generated artwork. Generate variants directly from the base, never from a preceding variant.

Keep the exact canvas aspect ratio, camera angle, character size, position, margins, ground contact and original ground shadow. Keep the plain white background. Add only the requested costume overlays and separate stationary props. Fit clothes to the existing body without reshaping it; keep the face, collar, paws, feet and tail unobscured. Props must rest on the ground beside the dog, not be held, worn on a paw, used or placed under its feet. If an accessory would require a pose change or hide a body part, place it beside the dog instead. No additional characters, human hands, extra limbs, text, letters, numbers, labels, logos, watermark, border or card frame. The character must remain in the same pose as the base in every variant.

# TASK-HUB-004 — ทดสอบกับผู้เล่นใหม่

สถานะ: พร้อมดำเนินการ; ยังไม่มีผลจากคนจริง
วันที่เตรียม: 2026-10-15
ผู้ใช้ยืนยันว่ามีคนพร้อมแล้ว; ผู้ดำเนินการต้องบันทึกผลจริงด้านล่างก่อนปิดงาน

## เตรียมรอบ

ใช้ build ที่ผ่าน regression ของ branch `feature/hub-workflow-verification` บนเครื่องหรือ preview ที่ผู้เข้าร่วมเข้าถึงได้ บันทึก commit และ URL ของ build โดยไม่ใส่ room code, invite token หรือ reconnect token ในรายงาน อย่าใช้ production deployment เก่ามาอ้างว่าเป็นผลของ branch นี้

จัดกลุ่มใหม่ A และ B กลุ่มละ 3–5 คน และคู่ C อีก 2 คน รวม 8–12 คน ผู้เล่นแต่ละกลุ่มไม่เคยใช้ flow ที่ทดสอบมาก่อน ให้ใช้ชื่อเล่นชั่วคราวในเกม แต่ไม่บันทึกชื่อในผล สลับภาษา TH/EN และหน้าจอ 360/390/desktop ตามอุปกรณ์จริง บันทึกเฉพาะจำนวนแต่ละประเภท

กลุ่ม A/B เล่นเกมที่รองรับจำนวนคนจริง เช่น RPS All At Once และ Cluecanvas คู่ C เล่น Classic XO และ RPS ให้แต่ละกลุ่มทำรอบแรกและรอบสองกับกลุ่มเดิม ทดสอบมือถือหลังเปลี่ยน onboarding ด้วย ไม่ใช้ simulated players แทนคนจริง

## ข้อความให้ผู้เล่น

“สร้างห้องส่วนตัว เลือกเกม แล้วส่งลิงก์เชิญให้เพื่อน เข้าห้องและเริ่มเกม ทำสิ่งที่เกมขอจนจบรอบ จากนั้นเล่นอีกรอบกับเพื่อนกลุ่มเดิม ระหว่างเล่นให้ลองออกจากเครือข่ายชั่วครู่หนึ่งครั้งแล้วกลับมา หากไม่รู้ว่าจะทำอย่างไรให้พูดออกมา”

ผู้ดำเนินการอ่านโจทย์เท่านั้น อย่าบอกปุ่มหรือวิธีทำก่อนผู้เล่นขอความช่วยเหลือ หากต้องช่วยให้นับเป็นไม่สำเร็จแบบไม่ช่วย อย่าขอให้ผู้เล่นเปิดเผย role/word/hand หรือถ่ายภาพข้อมูลลับ

## วิธีวัด

- invite-to-join: วินาทีจากผู้รับเปิดลิงก์จน server ยืนยันว่าเข้าห้องแล้ว นับจำนวนคนเข้าห้องสำเร็จ/จำนวนคนที่ได้รับเชิญด้วย
- first accepted action: จำนวนผู้เล่นที่ server ยอมรับ action แรกโดยไม่ถามผู้ดำเนินการ / จำนวนผู้เล่นที่มีสิทธิ์ทำ action (ไม่นับผู้ชมและบทบาทที่ต้องรอ); นับเพียงครั้งเดียวต่อคนต่อรอบ
- invalid actions: จำนวน action ที่ server ปฏิเสธ แยกจากการกดปุ่ม disabled
- missed taps: จำนวนการแตะที่ผู้เล่นตั้งใจสั่งงานแต่ไม่ได้ผลตามเจตนา บันทึกเฉพาะชื่อ control/phase และจำนวน
- recovery: จำนวน reconnect สำเร็จ/จำนวนครั้งที่ทดลอง พร้อมเวลารอรวม; ตรวจว่ากลับที่นั่งเดิมและ draft/turn ต่อได้
- second round: จำนวนกลุ่มที่เริ่มรอบสองกับกลุ่มเดิม / 3 กลุ่ม พร้อมจำนวนคนที่เล่นต่อ

เก็บเฉพาะ aggregate ไม่มี names, room codes, secret words, roles, cards, tokens, raw socket payloads หรือ raw state

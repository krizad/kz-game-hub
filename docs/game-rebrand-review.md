# ผลปรับชื่อและภาพลักษณ์เกม

อัปเดต 8 ตุลาคม 2569 — ฉบับในเครื่อง ปรับโค้ดครบ 5 เกมแล้ว; ยังไม่ใช่การรับรองสิทธิ์และยังไม่เผยแพร่

## สิ่งที่ปรับแล้ว

| รหัสภายใน        | ชื่อไทย / อังกฤษ                | การปรับที่ผู้เล่นเห็น                                                                                                |
| ---------------- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `SOUNDS_FISHY`   | คำตอบพราง / GuiseGuess          | ผู้ตรวจคำ ผู้ถือเฉลย ผู้พรางคำ; เปลี่ยนภาพปลาเป็นกุญแจ/หน้ากาก/ข้อความและใช้โทนเขียวกับอำพัน                         |
| `DETECTIVE_CLUB` | รหัสภาพ / Cluecanvas            | ผู้ตั้งรหัส ผู้ไร้รหัส ผู้ถอดภาพ; คืนการ์ด JPG เดิมที่ผู้ใช้สร้างเอง 80 ใบ; เขียนกติกาและข้อความคะแนนตามการทำงานจริง |
| `THE_MIND`       | นับในใจ / Countaline            | จังหวะพัก สายขึ้น/สายลง โหมดสองสาย; ไพ่โทนกระดาษและสัญลักษณ์ลม                                                       |
| `COUP`           | บ้านทรายทอง / Golden Sand House | คฤหาสน์สมมติ บทบาทและการกระทำตามรายละเอียดผู้ใช้ ใช้สัญลักษณ์ทั่วไปแทนภาพจากละคร                                     |
| `WHO_KNOW`       | รู้แล้วเนียน / Knowguise        | คนถือคำ คนรู้ คนทาย; เปลี่ยน RoleCard กติกา คำอธิบายและป้ายกำกับทั้งสองภาษา                                          |

ตารางชื่อหลักอยู่ที่ `apps/web/src/i18n/game-titles.ts` หน้าหลัก ห้อง กติกาและตั้งค่ารับชื่อผ่านคำแปลตามภาษาที่เลือก รวม metadata, alt text, tooltip และข้อความผิดพลาดที่เกี่ยวข้อง รหัสห้อง Socket event ประเภทเกมและคีย์ฐานข้อมูลคงเดิม

การปรับครั้งนี้เน้นชื่อ ภาพและข้อความ กลไกหลักยังใกล้เกมที่เป็นที่มาของชื่อเดิม จึงยังต้องตรวจความคล้ายก่อนเผยแพร่ ไม่อ้างว่าการเปลี่ยนชื่อทำให้หมดความเสี่ยงแล้ว

## ที่มาภาพ

- ผู้ใช้ยืนยันเมื่อ 8 ตุลาคม 2569 ว่า JPG เดิมทั้ง 80 ใบเป็นภาพที่สร้างเอง และขอให้นำกลับมาใช้ คืนไฟล์ครบแล้วที่ `apps/web/public/images/detective-club/` พร้อมบันทึกคำยืนยันใน `manifest.json` โดยไม่สมมติเครื่องมือหรือใบอนุญาตที่ผู้ใช้ไม่ได้ระบุ
- ตัวโหลดเริ่มต้นรับ JPG/PNG/JPEG ตามชุดเดิม; การตั้งไดเรกทอรีเองยังรองรับ SVG ด้วย
- SVG ที่สร้างทดแทนก่อนหน้านี้ย้ายไปเก็บใน `docs/archive/cluecanvas-vector-deck/` ไม่ได้ลบทิ้ง เครื่องมือ `scripts/generate-cluecanvas-deck.mjs` เขียนลงโฟลเดอร์เก็บนี้ จึงไม่แทนที่การ์ดผู้ใช้เมื่อเรียกอีกครั้ง

## กติกาที่แก้ให้ตรงระบบ

รหัสภาพเริ่มด้วยการ์ดคนละ 5 ใบ ผู้ตั้งรหัสเริ่มวางทั้งสองรอบและเติมการ์ดหลังวาง ผู้ถอดภาพที่ทายถูกได้ 3 คะแนน หากผู้ไร้รหัสได้รับเสียงไม่เกิน 1 เสียง ผู้ไร้รหัสได้ 5 และผู้ตั้งรหัสได้ 4 คะแนน; ตั้งแต่ 2 เสียงขึ้นไปทั้งสองได้ 0 แก้ข้อความและผลสรุปที่เคยบอกว่าถูกจับทันทีที่มีหนึ่งเสียง โดยไม่เปลี่ยนการคิดคะแนนของเซิร์ฟเวอร์

รู้แล้วเนียนอธิบายเวลาตามค่าที่ตั้งในห้อง นับในใจอธิบายชีวิต/จังหวะพักที่ตั้งได้และโหมดซ่อนเลขของตนเอง บ้านทรายทองยังหงายการ์ดหนึ่งใบเมื่อกางพินัยกรรม และตกรอบเมื่อเสียทั้งสองใบ

## ผลค้นชื่อเบื้องต้น

ค้นวันที่ 8 ตุลาคม 2569 ฐาน [กรมทรัพย์สินทางปัญญา](https://search-new.ipthailand.go.th/) แสดงข้อมูลล่าสุดถึง 7 ตุลาคม 2569 การค้นเป็นข้อความตรงในชุดข้อมูลทั้งหมด ไม่ใช่การตรวจคำอ่าน โลโก้ หรือชื่อใกล้เคียงโดยผู้เชี่ยวชาญ

| คำค้น             | สิ่งที่ตรวจพบ                                                                                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| GuiseGuess        | หน้าผลค้น DIP แสดง 0 รายการ                                                                                                                                        |
| Cluecanvas        | หน้าผลค้น DIP แสดง 0 รายการ; ค้นเว็บพบใช้เป็นชื่อองค์ประกอบใน [ตัวอย่างโค้ด](https://codepen.io/kevthunder/pen/xpBpxb) ยังไม่ใช่หลักฐานทะเบียนชื่อเกม              |
| Countaline        | หน้าผลค้น DIP แสดง 0 รายการ แต่มีใช้กับ [เครื่องนับอิเล็กทรอนิกส์ CC701](https://a365.acdc.co.za/Images/spec/CC701.pdf); ต้องตรวจสินค้า/บริการและความเกี่ยวข้องต่อ |
| นับในใจ           | หน้าผลค้น DIP แสดง 0 รายการ                                                                                                                                        |
| Golden Sand House | หน้าผลค้น DIP แสดง 0 รายการ                                                                                                                                        |
| บ้านทรายทอง       | DIP พบ 9 รายการ: เครื่องหมายการค้า 4 และลิขสิทธิ์ 5 รายการ ดูรายละเอียดด้านล่าง                                                                                    |

รายการบ้านทรายทองที่เห็นในหน้าแรก: คำขอเครื่องหมายการค้า 542312 (จำหน่าย/เพิกถอน) และ 190146233, 190146243, 190146249 (จดทะเบียน) ทั้งหมดจำพวก 3; ลิขสิทธิ์ภาพยนตร์คำขอ 80469 ระบุบริษัท ไฟว์สตาร์ โปรดักชั่น จำกัด และรายการเพลง/ศิลปกรรมอื่น การมีรายการเหล่านี้ไม่ได้ตัดสินสิทธิ์ใช้ชื่อกับเกม แต่ต้องตรวจสถานะ ขอบเขตและผู้ถือสิทธิ์ต่อ โดยเฉพาะภาพจำคฤหาสน์และตัวละคร

ชื่อไทยคำตอบพราง รหัสภาพ รู้แล้วเนียน, Knowguise และชื่อสำรอง **คฤหาสน์คนลวง / Mask Manor** ยังต้องเก็บผลทะเบียนฉบับสมบูรณ์ รวมคำใกล้เคียงและการใช้จริงในร้านแอป/เกม ก่อนยืนยันสำหรับเผยแพร่ การไม่พบผลค้นไม่เท่ากับชื่อว่างหรือปลอดสิทธิ์ [WIPO แนะนำให้ตรวจทะเบียนประเทศเพิ่มเติมจากฐานสากล](https://www.wipo.int/en/web/global-brand-database)

การตัดสินใจล่าสุดของผู้ใช้ (8 ตุลาคม 2569): ยืนยันใช้ **บ้านทรายทอง / Golden Sand House** และ **นับในใจ / Countaline** ต่อ เพราะโครงการไม่แสวงกำไร จึงคงชื่อในแอปและไม่สลับเป็นชื่อสำรองอัตโนมัติ คฤหาสน์คนลวง / Mask Manor คงเป็นตัวเลือกในอนาคต

การยืนยันนี้เป็นการเลือกชื่อของผู้ใช้ ไม่ใช่การรับรองสิทธิ์ การไม่แสวงกำไรเพียงอย่างเดียวไม่ได้ทำให้เข้าเงื่อนไขยกเว้นลิขสิทธิ์ทั้งหมดโดยอัตโนมัติ ดูเงื่อนไขมาตรา 32 ใน [พระราชบัญญัติลิขสิทธิ์ ฉบับแก้ไขถึงปี 2565 ที่ WIPO Lex](https://www.wipo.int/wipolex/en/legislation/details/23909) ผลค้นเดิมยังเก็บไว้เป็นข้อมูลประกอบ

## การตรวจการทำงานก่อนคืนการ์ด JPG

ผลด้านล่างเป็นผลของรอบก่อนคืนการ์ด JPG (ตอนใช้ SVG); รอบคืนการ์ดแก้ข้อคาดหวังให้เป็น JPG แล้ว แต่ไม่ได้รันชุดทดสอบซ้ำ

- ตรวจชนิดข้อมูลของเว็บและ API ผ่าน
- API: 105 กรณีใน 5 ชุดที่เกี่ยวข้องผ่าน (รวมทดสอบตัวโหลด SVG และการเล่นเดิม)
- E2E: 30 กรณีไม่ซ้ำผ่าน ครอบคลุมภาษา สร้าง/เข้าห้อง ตั้งค่า กติกา และการเล่นรหัสภาพ นับในใจ รู้แล้วเนียน บ้านทรายทอง รวมการโหลด SVG จริง
- คำตอบพรางทดสอบตรรกะด้วยข้อมูลจำลองและสร้างห้อง; ยังไม่ทดสอบรอบเล่นผ่านเบราว์เซอร์ที่ต้องโหลดคำถามจากฐานข้อมูล
- ไม่แตะฐานข้อมูล production: E2E ใช้ URL ชี้ loopback ที่เชื่อมต่อไม่ได้และปิดการโหลด GameSetting จาก DB จึงยังไม่ยืนยันการบันทึกผลการแข่งขัน/ข้อมูลเดิมในฐานข้อมูล
- `git diff --check` ผ่าน

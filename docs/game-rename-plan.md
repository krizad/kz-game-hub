# แผนปรับชื่อและภาพลักษณ์ 5 เกม

สถานะ: ยืนยันแผนและปรับโค้ดทั้ง 5 เกมแล้ว (8 ตุลาคม 2569); ผู้ใช้ยืนยันใช้บ้านทรายทองและ Countaline ต่อสำหรับโครงการไม่แสวงกำไร ผลค้นสิทธิ์ยังเป็นข้อมูลประกอบที่ไม่ใช่การรับรองสิทธิ์ ดู [บันทึกผลงานและข้อจำกัด](game-rebrand-review.md)

## ขอบเขตและชื่อที่เลือก

| รหัสเกมเดิม (คงไว้ภายใน) | ชื่อไทยที่แสดง | ชื่ออังกฤษที่แสดง | สถานะ                                                                                                                                                            |
| ------------------------ | -------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SOUNDS_FISHY`           | คำตอบพราง      | GuiseGuess        | ปรับในแอปแล้ว; รอตรวจชื่อ                                                                                                                                        |
| `DETECTIVE_CLUB`         | รหัสภาพ        | Cluecanvas        | ปรับในแอปแล้ว; รอตรวจชื่อ                                                                                                                                        |
| `THE_MIND`               | นับในใจ        | Countaline        | ปรับในแอปแล้ว; ผู้ใช้ยืนยันชื่อ; พบการใช้ [Countaline กับสินค้าอิเล็กทรอนิกส์](https://a365.acdc.co.za/Images/spec/CC701.pdf) ต้องประเมินความเกี่ยวข้องของสินค้า |
| `COUP`                   | บ้านทรายทอง    | Golden Sand House | ปรับคำและธีมในโค้ดแล้ว; ผู้ใช้ยืนยันใช้ชื่อสำหรับโครงการไม่แสวงกำไร; ยังไม่มีการรับรองสิทธิ์                                                                     |
| `WHO_KNOW`               | รู้แล้วเนียน   | Knowguise         | ปรับในแอปแล้ว; รอตรวจชื่อ                                                                                                                                        |

ชื่อสำรองของ `COUP`: **คฤหาสน์คนลวง / Mask Manor** เก็บเป็นตัวเลือก ผู้ใช้ยืนยันล่าสุดให้ใช้ **บ้านทรายทอง / Golden Sand House** ต่อ จึงไม่สลับชื่ออัตโนมัติ หากจะใช้ชื่อสำรองภายหลังยังต้องตรวจสิทธิ์ของชื่อนั้น

หน้าเว็บแสดงชื่อไทยเมื่อเลือกภาษาไทย และชื่ออังกฤษเมื่อเลือกภาษาอังกฤษ ไม่มีชื่ออีกภาษาต่อท้ายในวงเล็บ เกมอื่นนอกตารางนี้ไม่อยู่ในรอบเปลี่ยนชื่อ

## ขอบเขตที่เปลี่ยนและสิ่งที่คงไว้

- เปลี่ยนชื่อ ข้อความอธิบาย กติกา ชื่อบทบาท/การกระทำที่ผู้เล่นเห็น ภาพประกอบ และสื่อแนะนำเกมของทั้ง 5 เกม
- คง `GameType`, ค่า Socket event, ชื่อคีย์สถานะ, คีย์ฐานข้อมูล `GameSetting.gameType` และ `GameResult.gameType`, ชื่อโมเดล Prisma, และชื่อไฟล์/โฟลเดอร์ภายใน เพื่อให้ห้องและสถิติเดิมยังอ้างเกมเดิมได้ การเปลี่ยนรหัสเหล่านี้เป็นงานย้ายข้อมูลและรองรับความเข้ากันได้ต่างหาก (ดู [ADR 0008](adr/0008-separate-game-titles-from-identities.md))
- ชื่อบทบาทและการกระทำที่ผู้เล่นเห็นแยกจากรหัสภายใน เช่น `Insider`, `CoupActionType.COUP`, `Blue Fish`, `Red Herring`, และ `Shuriken` จะได้รับคำใหม่ตามธีมที่ตกลงหลังตรวจความคล้ายของกติกา คำที่เป็นเพียงตัวระบุในโค้ดคงไว้
- สำหรับ `COUP` ใช้ฉากคฤหาสน์และบทบาทที่ผู้ใช้กำหนดโดยไม่เอ่ยชื่อตัวละครจากนวนิยาย/ละคร แต่ชื่อเกมและภาพจำของบทบาทยังอาจทำให้ผู้เล่นเชื่อมโยงกับผลงานเดิม จึงต้องตรวจสิทธิ์และความเสี่ยงก่อนเผยแพร่; งานรอบนี้ใช้สัญลักษณ์ทั่วไปแทนภาพตัวละคร

## ขั้นตอนงาน

### 1. ตรวจชื่อและสิทธิ์ก่อนยืนยันชื่อสำหรับเผยแพร่

1. ค้นชื่อไทย อังกฤษ คำอ่าน การสะกดใกล้เคียง และชื่อสำรองใน [ฐานค้นกรมทรัพย์สินทางปัญญา](https://search-new.ipthailand.go.th/) และ [WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database) โดยดูสถานะ ผู้ถือสิทธิ์ และสินค้า/บริการที่เกี่ยวกับเกม แอป และบริการเกมออนไลน์
2. ค้นการใช้จริงบนเว็บ ร้านแอป ร้านเกม ชื่อโดเมน และสื่อสังคมในตลาดไทย แล้วเก็บผลพร้อมวันที่ค้นและลิงก์อ้างอิง การไม่พบผลค้นเว็บไม่เท่ากับได้รับสิทธิ์ใช้ชื่อ
3. บันทึกข้อค้นพบของ **บ้านทรายทอง / Golden Sand House** และ **Countaline** ไว้ตามจริง ผู้ใช้ยืนยันให้ใช้ชื่อทั้งสองต่อสำหรับโครงการไม่แสวงกำไร การตัดสินใจนี้ไม่ถือเป็นผลตรวจสิทธิ์จากผู้เชี่ยวชาญ
4. ใช้ตารางชื่อเดียวที่ `apps/web/src/i18n/game-titles.ts` สำหรับฉบับปรับในเครื่องตามคำสั่งผู้ใช้; การมีชื่อในตารางนี้ยังไม่ถือว่าผ่านสิทธิ์สำหรับเผยแพร่

### 2. ตรวจความคล้ายของกติกา คำ และภาพ

1. เทียบคำอธิบาย การ์ด บทบาท การให้คะแนน ตัวช่วย ไอคอน และลำดับรอบของ 5 เกมกับงานที่อาจเกี่ยวข้อง ระบุส่วนที่ต้องออกแบบใหม่ ไม่คัดลอกข้อความกติกาหรือภาพของเกมอื่น
2. `SOUNDS_FISHY`: เปลี่ยนชื่อบทบาทและภาพปลา/สีที่ทำให้โยงกับ Blue Fish และ Red Herring; ตรวจชุดคำถามและข้อความอธิบาย
3. `DETECTIVE_CLUB`: ใช้ภาพการ์ด JPG เดิม 80 ใบที่ผู้ใช้ยืนยันว่าสร้างเองและขอให้คืนกลับ (8 ตุลาคม 2569) บันทึกที่มาใน manifest และลบการอ้าง _Dixit_ ในข้อความที่ผู้เล่นเห็น
4. `THE_MIND`: ตรวจรูปแบบไพ่ ระดับ ตัวช่วย Shuriken และโหมดต่าง ๆ; กำหนดตัวช่วยและภาพใหม่พร้อมกติกาที่อธิบายด้วยภาษาของเกมนี้
5. `COUP`: ออกแบบการ์ด บทบาท ไอคอน และข้อความตามคฤหาสน์สมมติ ตรวจว่ากติกา/ความสามารถยังใกล้เกมเดิมเพียงใด และปรับส่วนที่จำเป็นโดยคงความเข้ากันได้ของรหัสภายในหรือวางงานย้ายข้อมูลแยกหากต้องเปลี่ยนโครงสร้าง
6. `WHO_KNOW`: เปลี่ยนชื่อบทบาท `Insider` ที่แสดงต่อผู้เล่นและคำอธิบายที่อ้างเกม _Insider_; ตรวจโครงรอบและข้อความกติกา

### 3. ปรับผลิตภัณฑ์และเนื้อหาทุกจุดที่ผู้เล่นเห็น

1. ใช้ชื่อจริงจากตารางเดียวในคำแปล `apps/web/src/i18n/dictionaries/en.ts` และ `th.ts`; ตรวจ `lobby.gameNames`, แท็บและเนื้อหากติกา, ชื่อในหน้ารอ, ปุ่ม, บทบาท, ผลเกม, และข้อความสถานะทั้งสองภาษา
2. ตรวจจุดที่ประกอบชื่อเกมใน `HomeView.tsx`, `RoomHeader.tsx`, `RulesModal.tsx`, `LobbyRules.tsx`, `AdminGameSettings.tsx` และหน้า leaderboard ให้ชื่อห้อง/การ์ด/กติกา/ตั้งค่า/สถิติเรียกจากคำแปลเดียวกัน
3. แก้ข้อความที่เขียนตรงนอกพจนานุกรม เช่น `RoleCard.tsx`, `CoupView.tsx` และ metadata ใน `apps/web/src/app/layout.tsx`; ตรวจชื่อใน alt text, aria label, tooltip, fallback และข้อความจากเซิร์ฟเวอร์ที่ส่งถึงผู้เล่น
4. เปลี่ยนภาพที่ไม่ผ่านการตรวจที่มา หรือยังมีชื่อ/สัญลักษณ์/รูปแบบที่ใกล้เกมอื่น ตรวจข้อความที่ฝังอยู่ใน SVG/PNG/JPG และจัดเก็บหลักฐานสิทธิ์ของภาพใหม่
5. ปรับ `README.md`, เอกสารแนะนำการใช้งาน และคำโปรโมตที่เป็นปัจจุบัน เอกสารประวัติการตัดสินใจคงบริบทเดิมไว้ได้ แต่เพิ่มหมายเหตุอ้างชื่อใหม่เมื่อจำเป็น เอกสารเทคนิคที่ใช้รหัสเดิมให้อธิบายความต่างระหว่างรหัสกับชื่อแสดงผล

### 4. ตรวจความครบก่อนเผยแพร่

- ค้นชื่อเดิมและคำที่เกี่ยวข้องทั่วโครงการ แล้วจัดแต่ละผลเป็น **ข้อความผู้เล่นเห็นที่ต้องเปลี่ยน**, **รหัสภายในที่คงไว้**, หรือ **เอกสารประวัติ**; ไม่มีผลที่ผู้เล่นเห็นหลงเหลือ
- ตรวจด้วยมือทั้งภาษาไทยและอังกฤษบนมือถือและจอใหญ่: หน้าหลัก ห้อง กติกา หน้าตั้งค่า บทบาท การเล่น ผลเกม และสถิติ
- ปรับข้อคาดหวังใน E2E ที่อ้างชื่อเดิม แล้วตรวจการสร้าง/เข้าห้อง การแสดงชื่อ และสถิติเกมเดิม โดยไม่แตะฐานข้อมูล production เพื่อเปลี่ยนชื่อ
- ตรวจว่าธงเปิด/ปิดเกมเดิมและผลการแข่งขันเก่ายังใช้รหัสเดิมและยังแสดงชื่อใหม่ได้
- คงชื่อบ้านทรายทองและ Countaline ตามการยืนยันล่าสุด โดยไม่พักเกมหรือเปลี่ยนชื่ออัตโนมัติจากสถานะผลค้น งานรอบนี้เป็นการปรับในพื้นที่ทำงาน; การเผยแพร่จริงเป็นงานแยก และผลค้นสิทธิ์ยังไม่ใช่การรับรองทางกฎหมาย

## ข้อค้นพบที่เป็นเหตุผลของแผน

- ชื่อผู้เล่นเห็นกระจายในคำแปลหลายหมวดและมีข้อความเขียนตรงในคอมโพเนนต์; การแทนข้อความทั่วโครงการโดยไม่แยกรหัสภายในอาจกระทบสถิติและการเปิด/ปิดเกม
- [Asmodee มีเกม Sounds Fishy](https://www.asmodee.it/product/sounds-fishy/) ที่ใช้ชื่อและแนวคำตอบจริง/ปลอม; [ไทยรัฐมีเนื้อหาละคร บ้านทรายทอง](https://www.thairath.co.th/novel/bansaitong/ep1/page1) ที่ใช้ชื่อตรงกับชื่อใหม่ที่เสนอสำหรับ `COUP`
- [WIPO ระบุว่าฐาน Global Brand Database ไม่ครอบคลุมทุกทะเบียนประเทศ](https://www.wipo.int/en/web/global-brand-database) จึงต้องตรวจฐานไทยแยกด้วย
